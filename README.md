# Bolt Player — Website Oficial

Reprodutor e plataforma de streaming IPTV ultrarrápida em 4K sem travamentos.

- **Domínio oficial:** [boltplayer.site](https://boltplayer.site)
- **Palavra-chave principal:** Bolt Player
- **Tecnologias:** TanStack Start, React 19, Vite, Tailwind CSS, TypeScript.

## Funcionalidades e Otimizações

- Hero cinematográfico com imagem em formato WebP otimizada para dispositivos móveis e desktop (baseado no filme do TMDB com enquadramento centralizado).
- Paleta visual baseada no tema escuro cósmico com alto contraste (Electric Volt Gold + Lightning Indigo) para máxima visibilidade e legibilidade de botões e CTAs.
- Integração direta com WhatsApp para suporte e liberação imediata de teste grátis e planos.
- 11 artigos originais e aprofundados no Blog com foco em SEO, Schema.org (BlogPosting, FAQPage, Product, BreadcrumbList), EPG e tutoriais.
- Geração automática de `sitemap.xml` e `rss.xml`.

## Desenvolvimento Local

```sh
pnpm install
pnpm dev
```

## Build de Produção

```sh
pnpm build
```
